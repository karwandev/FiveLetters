# FiveLetters
A Python-based Wordle guessing game where players have six attempts to guess a randomly selected five-letter word. The game provides color-coded feedback (green, yellow, and gray) to indicate correct letters, misplaced letters, and incorrect guesses. It includes input validation, a word dictionary, and an interactive menu.
